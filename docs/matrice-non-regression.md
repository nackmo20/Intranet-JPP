## Couverture Studio v2 — finalisation workflows métier

- `WF-CREATE-OVP` : import `plan.courses[]`, champs `course.*` et `course.meta.*`, filtre candidature individuelle, export Job `create` couvert par `ovp plan courses import`.
- `WF-SOFIA-SEPARATION` : recensement + Sofia-FMO uniquement, champs sessions/préinscription uniquement, places restantes calculées, aucune donnée éditoriale exportée, couvert par `sofia integration`.
- `WF-EDITORIAL-SEPARATION` : recensement + demandes éditoriales uniquement, champs éditoriaux autorisés uniquement, cellules vides ignorées, ligne retirée absente du Job, couvert par `editorial integration`.
- `WF-TAXONOMY-NODEID` : recensement + sélection manuelle par Node ID, add/remove/replace/clear, add exporte uniquement les nouvelles valeurs, couvert par `taxonomy integration`.
- `WF-NON-CONTAMINATION` : chaque workflow d'update exporte seulement sa liste blanche de champs et chaque opération possède un Node ID, couvert par `non contamination`.
