## Règles de reconnaissance
- Un onglet thématique est reconnu par structure lorsque les colonnes `Node ID Drupal`, `Lien de la page` et `Titre` sont présentes.
- Le nom commençant par `T` reste uniquement un indice secondaire, afin de reconnaître de futurs onglets par colonnes.
- Les colonnes inconnues sont conservées dans le JSON pour éviter les pertes de données.
